# v2026.09.25.1

Portable Windows build.

Changes:

- Configurable `runtime.max_books_per_pass` (default: 50) is available in setup and `config.json`.
- On a large Telegram backlog, keep the newest links and permanently skip older excess links by advancing the scan cursor.
- Discard excess unattempted Telegram books already queued by previous builds.
- Limit automatic processing to the configured number of books per pass. Explicit manual force runs are unaffected.

The bundled Chromium revision is unchanged from v2026.09.25. Users of that release can update by replacing the EXE only. Older installations should replace `ms-playwright` too.

This release provides both the full portable ZIP and a standalone EXE for users updating from v2026.09.25.

The ZIP contains the EXE, bundled Chromium, README and config example. It excludes user data, sessions, browser profiles, `config.json`, and the SQLite database.
