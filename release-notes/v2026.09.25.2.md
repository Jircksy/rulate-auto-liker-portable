# v2026.09.25.2

Fixed the backlog cap for books already stored in SQLite. The previous release capped newly scanned Telegram links but could still retry hundreds of older books whose bookmarks were left pending by the bookmark migration.

The automatic queue now retains only the newest `runtime.max_books_per_pass` pending books (50 by default), including old retry attempts. Older pending books are marked as skipped so they will not return in later passes. Their history stays in SQLite, and an explicit manual force run can reactivate an individual book.

The bundled Chromium revision is unchanged from v2026.09.25 and v2026.09.25.1. Users of either release can update by replacing the EXE only. Users of v2026.06.15 should install the full portable ZIP, keeping their `config.json` and `data` folder.

Assets: full portable ZIP and standalone EXE.
